# 📚 spring-boot-library-inventory-system

[![Java](https://img.shields.io/badge/Java-17-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)](https://openjdk.org)
[![Library](https://img.shields.io/badge/Domain-Circulation_State_Machine-blue?style=for-the-badge)](src/)

Library Catalog & Circulation Management System in Java with status state machines and ISBN indexing.

## Features
- **Circulation Lifecycle:** State machine enforcing valid borrow/return transitions.
- **ISBN Lookup:** O(1) in-memory indexing for fast book queries.
